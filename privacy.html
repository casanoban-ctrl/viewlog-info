개인정보처리방침

Viewlog가 사용하는 정보, 사용 목적과 사용자가 연결을 관리하는 방법을 설명합니다.

작성일: 2026년 11월 7일 · 공개 적용일은 최초 게시일입니다.

1. 적용 범위와 운영 주체

이 방침은 개인용 Viewlog 앱의 Google 캘린더 연결 기능과 이 공개 안내 사이트에 적용됩니다. 운영 주체는 개인용 Viewlog의 운영자이며, 공개 운영 계정은 casanoban-ctrl입니다. 별도의 사업자나 공개 회원제 서비스로 운영한다고 주장하지 않습니다.

2. Google에서 사용하는 정보와 권한

사용자가 직접 동의한 연결을 통해 캘린더 목록과 이름, 식별자, 시간대, 표시 정보 및 접근 역할을 확인합니다. 일정 기능에는 제목, 시작·종료 시간, 종일 여부, 반복 정보와 식별 정보가 사용됩니다. 사용자가 상세 조회·편집을 요청하면 메모·위치 등 해당 기능에 필요한 일정 정보도 처리할 수 있습니다.

요청하는 Google 권한은 다음 두 가지입니다.

  • calendar.events: 캘린더 일정 조회 및 앱이 지원하는 일정 추가·편집 기능을 위한 권한입니다. Google 권한의 허용 범위와 앱에서 실제 지원하는 기능은 같지 않을 수 있으며, 개별 변경에는 사용자의 요청과 확인이 필요합니다.
  • calendar.calendarlist.readonly: 접근 가능한 캘린더 목록을 확인하는 읽기 권한입니다.

Gmail 메일, Drive 파일, 주소록 권한은 요청하지 않습니다. Google 계정 비밀번호는 Viewlog에 입력하지 않습니다. 연결 유지에 필요한 OAuth 접근 토큰과 갱신 토큰은 앱 서버의 비공개 저장소에서 처리합니다.

3. 이용 목적과 AI 처리

정보는 일정 표시·동기화·브리핑, 사용자가 확인한 일정 추가·편집, 연결 상태 확인과 오류 복구에 사용합니다. 대화와 메모는 사용자가 요청한 정리와 답변 기능을 위해 처리합니다.

일정 관련 AI 기능을 요청하면 필요한 범위의 일정 정보와 질문이 사용자가 설정한 AI 제공자에게 전달될 수 있습니다. Google 접근 토큰·갱신 토큰·클라이언트 비밀정보는 AI 답변 입력에 포함시키지 않습니다. 외부 AI의 처리·보관에는 해당 제공자의 정책과 계정 설정도 적용되므로, 민감한 정보는 입력 전 설정과 전송 범위를 확인해야 합니다.

Viewlog는 Google 사용자 데이터를 광고 타기팅, 판매, 신용평가 또는 범용 AI 학습 데이터셋 제작을 목적으로 사용하지 않습니다. Google API에서 받은 정보의 사용과 전달에는 Google API 서비스 사용자 데이터 정책과 제한적 사용 요건을 적용합니다.

4. 저장과 보관

연결 정보와 일정 캐시, 사용자가 입력한 대화·메모 및 작업 결과는 개인용 앱을 운영하는 서버에 저장될 수 있습니다. 필요한 조회 범위, 동기화 상태와 기능 제공 목적에 따라 보관하며, 이 공개 안내 사이트나 공개 저장소에 올리지 않습니다.

Google 연결을 취소하는 것과 과거 대화·메모·백업을 삭제하는 것은 별개입니다. Google에서 연결을 취소해도 이미 저장된 기록이나 Google 캘린더 원본 일정이 자동으로 삭제되지는 않습니다. 삭제를 원하면 운영자에게 대상과 범위를 확인받아 요청할 수 있습니다. 백업·실행 이력의 보관 범위가 다를 수 있으므로, 삭제 요청을 처리할 때 남는 항목과 처리 결과를 별도로 안내합니다.

5. 제공자와 접근

Google은 인증과 캘린더 API 제공자로서 요청을 처리합니다. 사용자가 선택한 외부 AI 제공자는 요청된 AI 기능에 필요한 입력을 처리할 수 있습니다. 오류 조사나 지원을 위해 사람이 내용에 접근해야 한다면 사용자가 승인한 대상과 범위로 제한합니다. 법률상 의무나 보안 대응이 필요한 경우에는 필요한 범위에서 처리할 수 있습니다.

공개 안내 사이트는 GitHub Pages에 호스팅될 수 있습니다. 사이트 자체에는 광고, 분석 추적 스크립트, 로그인 폼 또는 Google API 호출을 넣지 않습니다. 다만 호스팅 제공자는 보안과 서비스 제공을 위해 IP 주소 등 기본 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

6. 연결 취소·삭제·문의

Google 계정의 서드 파티 연결 관리에서 Viewlog의 접근 권한을 취소할 수 있습니다. 이후 일정을 다시 사용하려면 앱에서 재연결이 필요합니다. Google에 저장된 원본 일정의 삭제·수정은 Google 캘린더에서 별도로 관리할 수 있습니다.

운영 문의는 공개 문의 창구로 문의 유형만 알려주세요. 공개 공간에는 이름, 이메일, 일정 제목, 대화 내용, 인증 코드·토큰을 올리지 마세요. 계정 확인이나 실제 데이터 삭제 등 비공개 처리가 필요하면 기존의 인증된 운영자 연락 경로를 이용하거나 비공개 전달 방법을 먼저 안내받으세요.

7. 방침 변경

사용 목적, 권한 또는 처리 방식이 달라지면 이 페이지를 갱신하고 필요한 경우 앱에서 추가 동의를 받습니다. 과거의 동의를 새로운 권한이나 별도 목적에 대한 동의로 간주하지 않습니다.
